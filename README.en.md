🌟 CAST-SITE-1 — Artistic & Spiritual Creation in HTML/JS
A multi-page website crafted with intention, blending aesthetics, logic, spirituality, and interaction.
This project is built with native HTML, CSS, and JavaScript, enhanced by Firebase (Authentication & Firestore) to offer a smooth, elegant, and secure experience.

🎯 Purpose
- Create a space of inspiration through art, poetic algorithms (like Fibonacci), and sacred voice.
- Allow members to create a profile, sign in, explore a dynamic gallery, and access personalized content.

🚀 Features
- 🔐 Email authentication using Firebase
- 📁 User profiles saved in Firestore
- 🎵 Sacred audio integration (chants, voice recordings)
- 🖼️ Dynamic gallery of visual content
- 🌿 Pages dedicated to poetry, engagement, and inner exploration
- 🔢 Fibonacci sequence-based interactions for creative stimulation

🧰 Technologies Used
- Native HTML / CSS / JavaScript
- Firebase (Authentication + Firestore)
- Vercel (deployment platform)
- Dynamic HTML components loading (header, footer, head, gallery)

📦 Installation & Launch
- Clone the project:
git clone https://github.com/LeMizoo/cast-site.git
- Open the folder in Visual Studio Code
- Create your own firebase-config.js file with your Firebase keys
- Launch with a local server (Live Server or npx serve recommended)

🔐 Security
Sensitive files like firebase-config.js and .env are protected by .gitignore.
This prevents API keys and private data from being uploaded accidentally.
